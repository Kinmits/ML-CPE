# ML-10 Object Detection II (YOLO)

This project applies the YOLO (You Only Look Once) architecture for fast and accurate object detection. It includes scripts to train the model with varying configurations, evaluate performance (Precision, Recall, mAP), and run inference on images and real-time webcam feeds.
